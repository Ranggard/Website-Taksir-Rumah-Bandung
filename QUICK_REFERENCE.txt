STEP-BY-STEP DEPLOYMENT (15 MINUTES)
================================================================================

STEP 1: Setup TiDB Database (5 min)
-----------------------------------
1. Go to: https://tidbcloud.com/
2. Sign up with GitHub
3. Click "Create Cluster"
4. Select "Serverless" (FREE!)
5. Name: prediksi-rumah-bandung
6. Region: Singapore
7. Create and wait for "Available" status
8. Click Cluster → Connect
9. Copy connection details

Save these credentials:
  Host: gateway01.ap-southeast-1.prod.aws.tidbcloud.com
  Port: 4000
  Database: prediksi_rumah_bandung
  Username: root
  Password: [YOUR_PASSWORD]

10. Go to Settings → IP Whitelist
11. Add: 0.0.0.0/0 (Allow All)
12. Create database:
    CREATE DATABASE prediksi_rumah_bandung;

STEP 2: Deploy to Render (5 min)
---------------------------------
1. Go to: https://dashboard.render.com/
2. Sign up with GitHub
3. Click "+ New" → "Web Service"
4. "Build and deploy from Git"
5. Connect GitHub account
6. Select: Website-Taksir-Rumah-Bandung
7. Configure:
   - Name: taksir-rumah-bandung
   - Environment: PHP 8.3
   - Region: Singapore
   - Plan: Free
   
   Build Command:
   composer install --optimize-autoloader --no-dev && npm install && npm run build
   
   Start Command:
   php artisan migrate --force && php -S 0.0.0.0:$PORT public/index.php

8. Click "Create Web Service"
9. Wait for deployment (check Logs tab)

STEP 3: Environment Variables (3 min)
--------------------------------------
1. From local terminal, generate APP_KEY:
   php artisan key:generate --show
   (Copy the output)

2. In Render Dashboard:
   - Click your service
   - Settings → Environment
   - Add these variables:

APP_NAME=Taksir Rumah Bandung
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-service.onrender.com
APP_KEY=base64:[PASTE_FROM_ABOVE]
DB_CONNECTION=mysql
DB_HOST=gateway01.ap-southeast-1.prod.aws.tidbcloud.com
DB_PORT=4000
DB_DATABASE=prediksi_rumah_bandung
DB_USERNAME=root
DB_PASSWORD=[YOUR_TIDB_PASSWORD]
DB_CHARSET=utf8mb4
DB_COLLATION=utf8mb4_unicode_ci
SESSION_DRIVER=database
QUEUE_CONNECTION=database
CACHE_STORE=database
LOG_CHANNEL=stderr

   - Click Save

3. Render automatically redeploys

STEP 4: Verify (2 min)
----------------------
1. Wait for status to show "Live" (green)
2. Click the service URL
3. Test in browser
4. Check Logs for errors

DONE! 🎉

COMMON ISSUES & FIXES
================================================================================

BUILD FAILED?
→ Check Render Logs tab for error message
→ Verify build command
→ Ensure git push was successful

DATABASE CONNECTION ERROR?
→ Check TiDB credentials are correct
→ Verify database "prediksi_rumah_bandung" exists
→ Check IP whitelist: 0.0.0.0/0 allowed?

APP_KEY ERROR?
→ Generate locally: php artisan key:generate --show
→ Copy entire output (including "base64:" prefix)
→ Paste in Render APP_KEY environment variable

500 ERROR IN BROWSER?
→ Check Render Logs
→ Verify database connection
→ Ensure migration ran
